# Task: User model and session dependency

**Task:** T2
**Wave:** 1
**Status:** done

## Objective

Create the `User` SQLAlchemy model and a request-scoped database session.

## Acceptance

- [x] `id` is a UUID string primary key generated by the application.
- [x] `email` is unique, indexed, and normalized to lowercase before insert.
- [x] `hashed_password` is required and never selected into API responses.
- [x] `role` is constrained to `user` or `admin`.
- [x] `created_at`/`updated_at` are set by the database.
- [x] The session dependency closes the session after the request.

## Notes

Use a Pydantic response model that excludes `hashed_password` rather than relying
on every handler to remember to omit it.
