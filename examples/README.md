# Examples

Real-world examples of using Project Development Skills.

## Structure

```
examples/
├── api-project/
│   ├── README.md           # Example: REST API with FastAPI
│   └── .spec/              # Example .spec/ structure
├── frontend-app/
│   └── README.md           # Example: React frontend
└── microservice/
    └── README.md           # Example: Docker microservice
```

## How to Use

1. Browse examples for your use case
2. Copy the relevant structure
3. Adapt to your project

## Creating Examples

To add a new example:

1. Create directory: `examples/<example-name>/`
2. Add `README.md` with:
   - Project description
   - Skills used
   - Step-by-step walkthrough
   - Generated artifacts (`.spec/`, etc.)
3. Submit PR
