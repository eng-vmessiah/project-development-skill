## Pegadinha de ambiente (não é doc, é execução)

`scripts/pd` fixa `~/.venvs/pd/bin/python3`, mas um `python3` no PATH resolve para o venv canário do
Hermes, **sem PyYAML** — então `python3 scripts/pd.py ... --plan <manifesto>.yaml` falha com
"PyYAML não está instalado". O exemplo JSON do README sobrevive só porque o manifesto é `.json`.
Use `/usr/bin/python3` para qualquer coisa que leia manifesto YAML.
