# Karpathy guidelines reference

Use these local practices when optimizing prompts or AI-generated code:

1. Think before coding: state the goal, constraints, and evidence needed.
2. Prefer the simplest change that satisfies the stated goal.
3. Make surgical changes and avoid unrelated cleanup.
4. Execute toward a concrete, verifiable outcome rather than producing activity.

This is a narrow working reference for `ai-optimization`, not a claim of
external authorship or a replacement for repository-specific requirements.
